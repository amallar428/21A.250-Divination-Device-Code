# 21A.250-Divination-Device-Code

The Loom of Echos is a divination device that reveals the weave of destiny. It was conceptualized as a project for MIT's Fall 2025 21A.520 Magic, Science, and Religion course. Drawing from various discussions around ritual, cosmology, and perception, the Loom aims to bridge persistent symbolism, open metaphor, and color theory with digital aesthetics. The interpretive language of the Loom draws on cross-cultural divinatory systems: pattern recognition as revelation (e.g., I Ching hexagrams, Tarot spreads), vibration and resonance as metaphors for cosmic alignment, and material metaphors (e.g., weaving, echoes, light) as tools of knowing.

## Usage
Simply clone the repository to your local computer `git clone https://github.com/amallar428/21A.250-Divination-Device-Code.git` and open the index.html file in your browser of choice. You may then speak with the Loom of Echoes.
